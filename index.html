Инструкции для записи в NTAG216
1) Открой приложение NFC Tools (iOS/Android).
2) Выбери Write → Add a record → URL/URI → вставь ссылку на эту HTML‑страницу (или прямо на .usdz).
3) Нажми Write и поднеси метку.

Совет: если хочешь менять содержимое позже — запиши в метку ссылку на редирект (Netlify/GitHub Pages). Тогда можно менять AR‑модель и текст без переписывания метки.
